# ストア掲載文（日本語）— Many Tabs

## 名前

Many Tabs

## 短い説明（132 字以内）

サイドパネルとページ端の畳めるレールで、開いているタブを一覧・操作するローカル専用タブマネージャー

## 詳細説明

Many Tabs は、開いているタブをまとめて見渡し・操作するためのローカル専用タブマネージャーです。

**2 つの表示**

- **サイドパネル**: フル機能のタブ一覧。切替・閉じる・新規・検索（/）・ピン留め・ミュート・複製・グループ化・グループ間移動・ドラッグ＆ドロップでの並べ替えができます
- **ページ端のレール**: 閲覧中のページの辺に重なる畳めるタブ一覧。半透明のアイコン列・細い帯・近接まで隠す、の 3 モード。左右上下の 4 辺＋自由配置、範囲指定、ホバー展開に対応

**プライバシー設計**

- 外部通信は一切なし。データ収集・解析・テレメトリ・広告 ID なし
- 閲覧情報の保存もなし。タブのタイトル・URL は画面表示と検索にだけ使い、ストレージには書きません（`chrome.storage` / `localStorage` / IndexedDB 不使用）
- 設定はメモリ上だけに保持され、Chrome の再起動で消えます
- ページ本文は読み取らず・改変しません。レールは自前の Shadow DOM overlay を描くだけです
- リモートコードなし。すべてのコードは拡張内に同梱

**言語**

日本語・English に対応。既定はブラウザの表示言語に従い、拡張の設定メニューから切り替えもできます。

**権限について**

`tabs`（タブ情報の読み取りと操作）、`tabGroups`（グループ表示・作成）、`favicon`（タブのアイコン表示）、`sidePanel`、およびページ上にレールを描く content script を使用します。Chrome の権限警告は強く見えますが、読み取った情報はブラウザ内でのみ使われ、送信も保存もされません。詳しくはプライバシーポリシーをご覧ください。

## カテゴリ

仕事効率化（Productivity）

## スクショ案（1280x800 または 640x400 PNG）

1. サイドパネルで多数のタブを一覧・検索している様子
2. ページ右端の畳みレール（半透明アイコン列）と、ホバー展開したタブ一覧
3. レールの設定メニュー（モード・位置・自動展開・言語）
4. タブのコンテキストメニュー（ピン・グループ化等）
5. 英語表示のサイドパネル or レール
