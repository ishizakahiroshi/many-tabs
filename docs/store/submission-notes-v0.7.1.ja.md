# 提出メモ v0.7.1（日本語・審査担当者向け）

## 単一目的の説明（Single Purpose）

開いているタブの一覧表示と操作（切替・閉じる・新規・検索・ピン・ミュート・複製・グループ・並べ替え）を、Chrome サイドパネルとページ端の畳めるレールで提供するタブマネージャー。それ以外の機能はありません。

## 権限の必要性

| 権限 | なぜ必要か |
|---|---|
| `sidePanel` | タブ一覧 UI を Chrome のサイドパネルに表示するため（この拡張の主画面） |
| `tabs` | タブのタイトル・URL・favicon・グループ所属を読み、一覧表示・検索と、切替・閉じる・ピン・ミュート・複製・並べ替えの各操作を行うため |
| `tabGroups` | タブグループの名前・色を表示し、グループの新規作成・追加・解除を行うため |
| `favicon` | Chrome 内蔵 `_favicon` エンドポイント経由でタブのアイコンを描画するため（外部への画像要求はなし） |
| content scripts（`rail.js` / `http://*/*` `https://*/*` `file:///*`） | ページの辺に畳めるタブレールを Shadow DOM overlay として描画するため。`<all_urls>` ではなく明示の 3 スキームに限定。`file:///*` はローカル HTML を開いたときにも同じ UX を提供するためで、ユーザーが file を開かなければ動作しません |

## リモートコード

使用していません。実行されるコードはすべて拡張パッケージ内のファイルです（`background.js` / `rail.js` / `rail-config.js` / `sidepanel.js` / `i18n/*.js`）。外部スクリプト・CDN・評価実行（eval）はありません。

## データ収集

ありません。`fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` は実装しておらず、CSP は `connect-src 'none'` です。`chrome.storage` / `localStorage` / IndexedDB も使わず、設定はメモリ上のみで再起動時に消えます。プライバシーポリシーは `PRIVACY.md`（公開リポジトリ）に掲載しています。

## 確認方法

1. 拡張を読み込み、ツールバーのアイコンでサイドパネルを開く（`openPanelOnActionClick`）
2. 任意の http/https ページを開くと右端に半透明のタブレールが表示される
3. レールの歯車メニューから表示モード・位置・自動展開・言語を切替できる
4. タブ行の「…」または右クリックでタブ操作メニュー
5. 権限警告のとおりタブ情報を読みますが、外部送信はありません（`tests/security-check.py` で機械検査も可能）

## 既知の制約

- Chrome 116+ が必要（`minimum_chrome_version`）
- レールは content script 注入のため、`chrome://` ページやウェブストアページ等の注入不可ページには出ません
- `file:///*` での表示は Chrome の「ファイルの URL へのアクセスを許可」がオンの場合のみ
