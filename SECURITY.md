# Security Policy — Many Tabs

**English** | [日本語は後半](#日本語)

## Reporting a vulnerability

Please report security issues privately, not through public Issues: open this
repository's **Security** tab on GitHub and choose **Report a vulnerability**
(GitHub private vulnerability reporting). Public Issues are visible to everyone,
so an unfixed problem posted there can be exploited before a fix ships.

A useful report includes:

- the extension version (shown on `chrome://extensions`) and the Chrome version
- the steps to reproduce
- what an attacker can do or learn, as far as you observed it

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Response

Many Tabs is a personal project maintained on a best-effort basis. There is no
guaranteed response time; reports are acknowledged as soon as possible, and the
fix is noted in `CHANGELOG.md` once released.

## 日本語

## 脆弱性の報告

セキュリティ上の問題は、公開の Issues ではなく非公開で報告してください。
GitHub のこのリポジトリの **Security** タブを開き、**Report a vulnerability**
を選びます（GitHub の非公開の脆弱性報告）。公開の Issues は誰でも読めるため、
直す前の問題を書くと、修正が出る前に悪用されるおそれがあります。

報告に含めてほしいこと:

- 拡張の版（`chrome://extensions` に表示）と Chrome の版
- 再現の手順
- 攻撃する側に何ができるか・何が分かるか（確かめた範囲で）

## 修正の対象

修正するのは `main` ブランチの最新版だけです。

## 対応

Many Tabs は個人のプロジェクトで、できる範囲で対応します。返答までの時間は
約束できませんが、届いた報告にはできるだけ早く返信し、修正を出したときは
`CHANGELOG.md` に記載します。
