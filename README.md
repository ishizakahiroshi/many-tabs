# Many Tabs — 画面の辺のタブ一覧（試作版 v0.7.1）

Chrome拡張機能（Manifest V3）。画面の辺にローカルで動くタブ一覧を表示します。表示は2系統: Chrome標準の**サイドパネル**（機能フル）と、各ページの辺に重ねる最小表示の**レール**（アイコン列・ホバーでタイトル/設定で展開）です。

## インストール（Windows）

1. ZIPを任意の場所に展開します。ZIPファイル自体は読み込めません。
2. Chromeで `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を選び、展開した **`many-tabs` フォルダ**を指定します。
5. Chromeの **設定 → デザイン（または外観）→ サイドパネル → 右側** を選びます。名称はChromeの版で多少異なります。
6. ツールバーの拡張機能（パズル）から **Many Tabs** を開き、必要ならピン留めします。拡張機能のアイコンを押すとサイドパネルが開きます。

> **重要:** Chrome本体の「垂直タブ」機能を置き換えるものではありません。Chrome標準の垂直タブをオフ（上側の横タブに戻す）にしてから使うことを想定しています。上側の横タブもこの拡張機能では非表示にできません。

## 機能

### 画面の辺のレール（v0.2.0〜）

- 全ページの画面端（既定は右）に 44px のアイコン列を常駐表示。畳んだ状態は半透明の表示のみで、隙間のクリックやホイールはページへ通します（ページ側の右端ボタン・スクロールバーを塞ぎません）
- **自動展開は既定 OFF**（v0.7.0〜）: 畳んだ帯のアイコンを押せばタブ切替、帯は広がりません。アイコンにホバーすると、そのアイコンの隣に × ボタンが出てそのタブを閉じられます（上下・左・浮き配置の帯でも同様・v0.7.1〜）。あわせてタイトルのラベルが帯の外（ページ側）に出ます。帯の一番下の歯車の設定メニューで「自動で展開する」を選ぶと、カーソルを画面端まで動かす（またはアイコン列へ少しの間乗せる）だけで約 236px に展開する従来の動作に戻せます。OFF でも歯車メニューの「レールを開く」や `/` キーで明示的に開けます
- 畳み表示は 3 モード: 半透明（既定）/ 細い帯（20px）/ 近接まで非表示。歯車またはレールの行以外を右クリックで切替（モードはそのタブ・位置と自動展開は全タブに効き、画面遷移・タブ移動をまたいで保持。メモリのみで再起動で消えます。既定・サイト別設定は `rail-config.js`）（v0.4.0〜）
- 位置は右（既定）/ 左 / 上 / 下の 4 か所から選べます。上・下は畳み時は 28px のアイコン横帯、展開時は 40px の横チップ帯（縦リストにはならず画面を塞ぎません）。上下はカーソルの接近・滞留では一切開かず、帯中央の矢印ツマミ（▾/▴）をクリックしたときだけ開閉します（v0.5.5〜）。畳んだ帯のアイコンはそのまま押せばタブ切替になります（アイコンのセルのみクリックを受け、隙間はページへ通ります）（v0.6.0〜）
- 歯車のすぐ上の「移動」ラベル（移動ハンドル）を画面の辺へドラッグすると、その辺へレールを付け替えられます。設定メニューの「位置:…」からも切替できます（v0.5.1〜）
- 帯が存在する範囲を辺の一部に絞れます（v0.7.0〜）。帯の両端の ▴▾（横帯は ◂▸）ツマミで長さを、帯の中央の ⇕（横帯は ⇔・ページ側へ突き出た小タブ）で範囲ごと移動。移動ハンドルを今いる辺の中でドラッグしても範囲移動になり、別の辺へ付け替えると全幅に戻ります。自動展開の端タッチ・滞留は範囲の内側だけに効きます。リセットはツマミのダブルクリックか設定メニューの「範囲をリセット」。範囲は全タブに共有されます
- 帯を辺から剥がして画面の好きな所に浮かせられます（v0.7.0〜）。移動ハンドル（または浮いている帯の ⇕ ツマミ）を画面中央へドラッグして離すとその場に浮き、画面端のゾーンへ落とせば吸着して元の辺に戻ります。設定メニューの「好きなところに配置」でも切替（その場で浮き出すので、あとはドラッグで位置決め）。浮いている帯の開閉は ▾/▴ ツマミか `/` キー。浮いている間は移動ハンドルの上の ↻ ボタンで縦レールと横帯（上下位置と同じチップ型）を切り替えられます。上・下の辺から引きずり出すと最初から横向きで浮きます。浮いている帯の両端のツマミ（横帯は ◂▸・縦帯は ▴▾）で帯の長さを変えられます（ダブルクリックで内容量に合わせた自動サイズへ戻す）。浮き位置・向き・長さは全タブに共有されます
- タブ切替・閉じる・新規作成。固定タブとタブグループ（色ドット）の表示
- 検索（タイトル・URL）。検索中・メニュー表示中・ドラッグ中は展開したままになります
- 右クリック / ⋯メニューから固定・解除、ミュート、複製、グループ操作、閉じる（v0.3.0〜）
- 同じグループ内 / 固定タブ同士のドラッグ並べ替え（v0.3.0〜）
- ページのコンテンツの上に重ねて表示（ページのレイアウトは動かしません）
- `chrome://` 系・Chromeウェブストア等の内部ページでは表示されません（content script が動かないため）

### サイドパネル

- タブ一覧（タイトル、サイト名、Chrome内蔵キャッシュからのfavicon）
- タブ切替、閉じる、新規作成、検索（タイトル・URL）
- 固定タブ、タブグループ表示・開閉
- 同じグループ内 / 固定タブ同士のドラッグ並べ替え
- グループ見出しへドロップして所属を変更（固定タブ以外）
- 右クリック / 3点メニューから複製、固定・解除、ミュート、グループ操作、閉じる
- `/` で検索欄へ移動、`Esc` で検索解除またはメニューを閉じる
- OSのダーク/ライトモードに対応

## セキュリティ / プライバシー

- **外部通信禁止のCSP:** 拡張機能のページには `connect-src 'none'` を指定し、接続先をブロックしています。
- **外部通信処理なし:** `fetch`、`XMLHttpRequest`、`WebSocket`、`sendBeacon`、外部SDK/CDN/広告・解析ライブラリは使用していません。
- **ページへの描画について:** v0.2.0 から画面の辺のレールのため content scripts（`http`/`https`/`file`、トップフレームのみ）を宣言しています。レールは closed Shadow DOM でページのCSS・JSから隔離して描画し、ページ内容の読み取り・変更・外部送信は実装していません。レールの検索欄は拡張側のページ（`search.html`）を iframe で入れており、打った文字は表示中のページのスクリプトから見えません。タブ操作は送り元と同じウィンドウのタブに限定します。
- **閲覧情報を保存しません:** ブラウザ内ストレージ・localStorage・サーバーへのデータ保存を実装していません。
- **取得する情報:** Chromeの `tabs` APIで、そのウィンドウのタブタイトル・URL・状態などを読み取ります。これらのデータは画面表示と検索にのみ利用します。
- **サイトアイコン:** ページのURLはChrome内蔵 `_favicon` URLに渡してアイコンを表示します。サイトの外部アイコンURLを直接読み込みません。
- **安全性の限界:** 拡張機能はユーザーがインストールしたプログラムです。コードを改変した場合やChromeの不具合等を含め「絶対安全」は保証できません。
- Chromeで表示中の**ウェブサイト自身による通信**は、この拡張機能の外部通信とは別です。

### 必要な権限

| 権限 | 利用目的 |
|---|---|
| `sidePanel` | サイドパネルにタブ一覧を配置 |
| `tabs` | タブタイトル/URLの取得、切替・作成・削除・並べ替え等 |
| `tabGroups` | タブグループの取得・開閉・変更 |
| `favicon` | Chromeの内蔵favicon画像を表示 |
| content_scripts（`http`/`https`/`file`） | 画面の辺のレールをページに描画 |

なお `tabs` 権限は**全タブのURLやタイトルへのアクセスを可能にする強い権限**です。自作であっても権限そのものは必要です。content scripts を宣言しているため、インストール時に「すべてのサイトのデータの読み取りと変更」系の警告が表示されます。ページへの描画に必要な権限で、実際の読み取り・変更・送信は行いません。

## 対応 / 既知の制約

- Chrome **116以上**（Chrome 157を想定）。通常のPC版Chromeで使用してください。
- **サイドパネルの左右位置はユーザーのChrome設定に依存**し、拡張機能側で固定しません。
- Chrome標準の上部横タブや左側垂直タブを**非表示にできません**。
- 複数ウィンドウの場合、それぞれのパネルでそのウィンドウのタブを表示します。
- Incognito（シークレットモード）では、別途ユーザーが拡張機能の使用を許可しなければ動きません。
- ドラッグ並べ替えは同じグループ内と固定タブ同士で対応。グループ間の移動はメニューから可能です（サイドパネルではグループ見出しへのドロップも可）。
- Chromeの内部ページや `file:` URLのfaviconは既定アイコンになることがあります。
- Chromeウェブストア**未公開**。公開前にChrome実機確認、UI検証、プライバシー説明、ストア規約対応などが必要です。

## 開発者向け

- `manifest.json`: 拡張機能の宣言・必要権限
- `background.js`: 拡張機能アイコンでサイドパネルを開く設定、レールへのタブ情報配信・操作中継
- `rail.js`: 画面の辺のレール（content script・Shadow DOM overlay）
- `rail-config.js`: レール畳み表示の既定（`collapsedMode`: `translucent` / `slim` / `hidden`、`position`: `right` / `left` / `top` / `bottom`、`autoExpand`: `false` / `true`）とホスト名ごとの `overrides`（干渉するサイトだけ `hidden` 等にできる）
- `sidepanel.html` / `styles.css`: サイドパネル画面
- `sidepanel.js`: タブ操作・イベント・ローカルUI
- `search.html` / `search.js` / `search.css`: レールの検索欄（レールに iframe で入れる拡張のページ）
- `icons/*.png`: ローカルアイコン
- `tests/security-check.py`: 禁止API・宣言の静的チェック

ファイルを更新後は `chrome://extensions` で「更新」ボタンを押し、さらに **開いているページを再読み込み**してください。ページ内のレール（content script）はページの読み込み時にだけ差し替わるため、更新前に開いていたページには古い表示が残ります（ブラウザの再起動でも構いません）。
