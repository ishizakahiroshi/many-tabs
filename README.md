# Right Tabs Local — 右側の垂直タブ（試作版 v0.3.0）

Chrome拡張機能（Manifest V3）。右側にローカルで動くタブ一覧を表示します。表示は2系統: Chrome標準の**サイドパネル**（機能フル）と、各ページの右端に重ねる最小表示の**レール**（アイコン列・hoverで展開）です。

## インストール（Windows）

1. ZIPを任意の場所に展開します。ZIPファイル自体は読み込めません。
2. Chromeで `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を選び、展開した **`right-tabs-local` フォルダ**を指定します。
5. Chromeの **設定 → デザイン（または外観）→ サイドパネル → 右側** を選びます。名称はChromeの版で多少異なります。
6. ツールバーの拡張機能（パズル）から **Right Tabs Local** を開き、必要ならピン留めします。拡張機能のアイコンを押すとサイドパネルが開きます。

> **重要:** Chrome本体の「垂直タブ」を右側に移すものではありません。Chrome標準の垂直タブをオフ（上側の横タブに戻す）にしてから使うことを想定しています。上側の横タブもこの拡張機能では非表示にできません。

## 機能

### 右端レール（v0.2.0〜）

- 全ページの右端に 44px のアイコン列を常駐表示。畳んだ状態は半透明の表示のみで、クリックやホイールはページへ通します（ページ側の右端ボタン・スクロールバーを塞ぎません）
- カーソルを画面右端まで動かす（またはアイコン列へ少しの間乗せる）と約 236px に展開してタイトル・操作を表示
- タブ切替・閉じる・新規作成。固定タブとタブグループ（色ドット）の表示
- 検索（タイトル・URL）。検索中・メニュー表示中・ドラッグ中は展開したままになります
- 右クリック / ⋯メニューから固定・解除、ミュート、複製、グループ操作、閉じる（v0.3.0〜）
- 同じグループ内 / 固定タブ同士のドラッグ並べ替え（v0.3.0〜）
- ページのコンテンツの上に重ねて表示（ページのレイアウトは動かしません）
- `chrome://` 系・Chromeウェブストア等の内部ページでは表示されません（content script が動かないため）

### サイドパネル

- タブ一覧（タイトル、サイト名、Chrome内蔵キャッシュからのfavicon）
- タブ切替、閉じる、新規作成、検索（タイトル・URL）
- 固定タブ、タブグループ表示・開閉
- 同じグループ内 / 固定タブ同士のドラッグ並べ替え
- グループ見出しへドロップして所属を変更（固定タブ以外）
- 右クリック / 3点メニューから複製、固定・解除、ミュート、グループ操作、閉じる
- `/` で検索欄へ移動、`Esc` で検索解除またはメニューを閉じる
- OSのダーク/ライトモードに対応

## セキュリティ / プライバシー

- **外部通信禁止のCSP:** 拡張機能のページには `connect-src 'none'` を指定し、接続先をブロックしています。
- **外部通信処理なし:** `fetch`、`XMLHttpRequest`、`WebSocket`、`sendBeacon`、外部SDK/CDN/広告・解析ライブラリは使用していません。
- **ページへの描画について:** v0.2.0 から右端レールのため content scripts（`http`/`https`/`file`、トップフレームのみ）を宣言しています。レールは closed Shadow DOM でページのCSS・JSから隔離して描画し、ページ内容の読み取り・変更・外部送信は実装していません。タブ操作は送り元と同じウィンドウのタブに限定します。
- **閲覧情報を保存しません:** ブラウザ内ストレージ・localStorage・サーバーへのデータ保存を実装していません。
- **取得する情報:** Chromeの `tabs` APIで、そのウィンドウのタブタイトル・URL・状態などを読み取ります。これらのデータは画面表示と検索にのみ利用します。
- **サイトアイコン:** ページのURLはChrome内蔵 `_favicon` URLに渡してアイコンを表示します。サイトの外部アイコンURLを直接読み込みません。
- **安全性の限界:** 拡張機能はユーザーがインストールしたプログラムです。コードを改変した場合やChromeの不具合等を含め「絶対安全」は保証できません。
- Chromeで表示中の**ウェブサイト自身による通信**は、この拡張機能の外部通信とは別です。

### 必要な権限

| 権限 | 利用目的 |
|---|---|
| `sidePanel` | サイドパネルにタブ一覧を配置 |
| `tabs` | タブタイトル/URLの取得、切替・作成・削除・並べ替え等 |
| `tabGroups` | タブグループの取得・開閉・変更 |
| `favicon` | Chromeの内蔵favicon画像を表示 |
| content_scripts（`http`/`https`/`file`） | 右端レールをページに描画 |

なお `tabs` 権限は**全タブのURLやタイトルへのアクセスを可能にする強い権限**です。自作であっても権限そのものは必要です。content scripts を宣言しているため、インストール時に「すべてのサイトのデータの読み取りと変更」系の警告が表示されます。ページへの描画に必要な権限で、実際の読み取り・変更・送信は行いません。

## 対応 / 既知の制約

- Chrome **116以上**（Chrome 157を想定）。通常のPC版Chromeで使用してください。
- **サイドパネルの左右位置はユーザーのChrome設定に依存**し、拡張機能側で固定しません。
- Chrome標準の上部横タブや左側垂直タブを**非表示にできません**。
- 複数ウィンドウの場合、それぞれのパネルでそのウィンドウのタブを表示します。
- Incognito（シークレットモード）では、別途ユーザーが拡張機能の使用を許可しなければ動きません。
- ドラッグ並べ替えは同じグループ内と固定タブ同士で対応。グループ間の移動はメニューから可能です（サイドパネルではグループ見出しへのドロップも可）。
- Chromeの内部ページや `file:` URLのfaviconは既定アイコンになることがあります。
- Chromeウェブストア**未公開**。公開前にChrome実機確認、UI検証、プライバシー説明、ストア規約対応などが必要です。

## 開発者向け

- `manifest.json`: 拡張機能の宣言・必要権限
- `background.js`: 拡張機能アイコンでサイドパネルを開く設定、レールへのタブ情報配信・操作中継
- `rail.js`: 右端レール（content script・Shadow DOM overlay）
- `sidepanel.html` / `styles.css`: サイドパネル画面
- `sidepanel.js`: タブ操作・イベント・ローカルUI
- `icons/*.png`: ローカルアイコン
- `tests/security-check.py`: 禁止API・宣言の静的チェック

ファイルを更新後は `chrome://extensions` で「更新」ボタンを押してください。
